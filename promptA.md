# `promptA` repository command

When the repository owner sends `promptA`, do not treat the word itself as the implementation contract.

Execute the canonical repository runner protocol at:

`docs/agent-prompts/prompt-a-runner.md`

Mandatory first steps are still to fetch current remote `main` and read repository-root `AGENTS.md`. The phase-specific Prompt A and its paired preregistered Prompt B must be selected from the current canonical handoff/durable repository history according to that runner protocol.
