## 二、P0 的結論目前可能下得太快

系統看到：

> 偏多 44.07%，偏空 52.08%，差距 8.01%。

所以推論偏多門檻要提高。

但程式的方向命中定義其實很直接：

- 預測偏多，收盤報酬大於 0 就是方向命中。
- 預測偏空，收盤報酬小於 0 就是方向命中。
- 中性預測則以實際報酬是否在 ±0.3% 內判定。fileciteturn14file0L6-L22

因此，偏多和偏空的命中率天然會受到當天上漲、下跌家數影響。

### 粗略做一次市場基準校正

| 方向 | 模型命中率 | 當日市場基準 | 超過基準 |
|---|---:|---:|---:|
| 偏多 | 44.07% | 上漲比例 41.09% | **+2.98%** |
| 偏空 | 52.08% | 下跌比例 49.86% | **+2.22%** |

原本看起來偏空比偏多好 8.01%，但扣除當天漲跌家數後，偏多反而粗略多出 **0.76 個百分點的相對能力**。

這不是說偏多規則一定沒問題，而是：

> **目前的 8.01% 差距，幾乎可以被當天「下跌家數比上漲家數多 8.77%」解釋。**

所以我會把 P0 改成：

### P0：先建立市場基準校正，再決定是否提高偏多門檻

而不是直接提高偏多門檻。

更嚴謹的版本應在相同產業、方向分數、風險環境內，比較偏多與偏空的「超額命中率」，而不是拿兩個原始百分比直接相比。

## 三、P0 的「276 錯誤」也有呈現上的問題

Dashboard 的程式直接把全體 `obvious_miss_count` 顯示為偏多門檻問題的影響數：

```text id="wfyiyb"
impact: 276 錯誤
```

但這 276 檔是**所有方向的明顯錯誤總數**，包含偏多、偏空、中性，並不代表調高偏多門檻後可以改善 276 檔。fileciteturn4file0L47-L54

正確的影響數應該是：

1. 目前屬於偏多的樣本；
2. 提高門檻後會降級成中性或被排除；
3. 其中原本預測錯誤的數量；
4. 同時扣掉原本預測正確、卻會被新門檻錯誤排除的數量。

也就是要呈現：

> 淨改善 = 避免的錯誤 − 被犧牲的正確案例

而不是顯示全體 276 檔。

程式其實已經有 `score_without_factor`、`raw_label_changed` 等反事實欄位，可以用來計算「拿掉某因子後，多少股票真的會改變方向」，但目前 dashboard 沒有把這些資訊彙總。fileciteturn14file0L120-L141

## 四、七日相對強勢：我認同要優先調查

這一項目前是最有價值的線索：

- 有七日相對強勢：362 檔
- 命中率：約 41.99%
- 沒有七日相對強勢：約 687 檔
- 推算命中率：約 50.07%
- 差距：-8.08%

在把股票暫時視為互相獨立的簡化假設下，這個差距的粗略 95% 信賴區間約為 **-14.4% 到 -1.8%**，並不太像單純抽樣波動。

但這裡仍有三個問題：

1. 同一天的 1,049 檔股票並非 1,049 個完全獨立樣本，股票會共同受到市場與產業影響。
2. 七日強勢股票可能集中在特定產業或高方向分數區間。
3. 「相對強勢」可能不是線性因子。中度強勢可能有效，但極端強勢可能已經過熱、容易均值回歸。

目前程式的因子關聯只是直接比較「有因子」和「無因子」的命中率，沒有控制方向、產業或分數，因此程式本身也標記為探索性關聯而不是因果。fileciteturn20file0L29-L50

我建議將七日相對強勢切成分位數，而不是只有 True／False：

| 七日相對強勢分位 | 建議判讀 |
|---|---|
| 0～20% | 明顯弱勢 |
| 20～60% | 一般 |
| 60～85% | 適度強勢 |
| 85～95% | 高強勢 |
| 95～100% | 可能過度延伸 |

再跟 RSI、20 日均線乖離、成交量、跳空幅度做交互分析。很可能真正應該降分的是「相對強勢＋過熱」，而不是所有相對強勢股票。

## 五、籌碼同步偏多與技術強勢：實驗方向對，但現在還不能下結論

目前畫面同時列出：

- 籌碼同步偏多：317 檔，命中率 40.69%
- 技術強勢：41 檔，明顯錯誤率 48.78%

這兩個數字不能直接放在一起比較，因為：

- 一個是「命中率」；
- 一個是「明顯錯誤率」；
- 317 與 41 是各自的邊際樣本數；
- 沒有顯示兩者同時成立的交集有多少檔。

技術強勢 48.78% 大約是 41 檔中有 20 檔明顯錯誤，樣本仍小；其粗略 95% 信賴區間約為 **34.3%～63.5%**，不確定性很大。

所以目前只能說：

> 技術強勢群組出現值得調查的異常，但尚未證明「籌碼與技術兩個弱條件疊加後誤升級」。

四象限拆解是正確下一步：

| 籌碼同步 | 技術強勢 | 要比較的結果 |
|---|---|---|
| 否 | 否 | 基準組 |
| 是 | 否 | 籌碼的增量價值 |
| 否 | 是 | 技術的增量價值 |
| 是 | 是 | 是否存在正／負交互效果 |

除了命中率，也要顯示：

- 樣本數
- 平均策略報酬
- 報酬中位數
- 明顯錯誤率
- 提高或移除因子後，真正改變方向的股票數

# 實際數字與預測之間，目前缺少什麼？

## 1. 現在主要是在評估方向，不是在評估預測價格

預測檔其實有情境目標區間、支撐壓力價位，覆盤程式也已計算：

- 實際收盤是否落入預測區間；
- 實際高低價是否碰到預測區間；
- 實際收盤距離預測區間多少；
- 支撐是否守住；
- 壓力是否突破。fileciteturn14file0L63-L117

但 dashboard 彙總時只保留：

- 是否有任一情境收盤命中；
- 是否有任一情境與當日高低價重疊。fileciteturn16file0L79-L125

這不足以回答「預測數字與實際差多少」。

應新增：

- 目標中點 MAE
- 目標中點 MAPE
- 預測區間涵蓋率
- 平均區間寬度
- 收盤距離區間平均誤差
- 支撐守住率／壓力突破率
- 區間太寬但看似命中的比例

否則一個非常寬的目標區間會很容易命中，卻沒有實際預測價值。

---

## 2. 命中不等於有交易價值

現在偏多股票只要上漲 `+0.01%` 就算方向命中；偏空只要下跌 `-0.01%` 就算命中。fileciteturn14file0L6-L15

但扣掉交易成本、滑價和買賣價差後，這類命中沒有經濟意義。

至少需要增加：

- ±0.3%、±0.5%、±1% 不同門檻的命中率；
- ATR 標準化報酬；
- 預測方向乘以實際報酬；
- 平均獲利、平均虧損；
- Profit Factor；
- 最大回撤；
- 扣除成本後報酬。

核心指標應該是：

> 策略報酬 = 預測方向 × 實際報酬

偏多為 `+1`，偏空為 `-1`，中性為 `0`。

47% 命中率仍可能賺錢，前提是正確時賺得大、錯誤時虧得小；相反，55% 命中率也可能虧錢。

---

## 3. 「明顯準確／明顯不準」不是兩套獨立驗證

方向結果使用收盤漲跌。

氛圍分數則同時使用：

- 收盤報酬
- 開盤至收盤報酬
- 開高走低／開低走高
- 放量上攻／下殺
- 上下影線

因此方向與氛圍都來自同一天同一組 OHLCV，不是互相獨立的證據。fileciteturn13file0L165-L217

「方向錯＋氛圍錯」可以作為嚴重錯誤標籤，但不應把它理解成模型同時被兩套獨立資料證明錯誤。

# 我認為最值得新增的五個評估角度

| 評估面向 | 建議指標 |
|---|---|
| 基準校正 | 相對當日漲跌基準的超額命中率、Balanced Accuracy |
| 分數校準 | 方向分數分桶後的實際命中率與平均報酬 |
| 數字誤差 | MAE、MAPE、區間涵蓋率、區間寬度 |
| 經濟價值 | signed return、長空組合差、Profit Factor、回撤 |
| 相對能力 | 個股報酬減大盤／產業報酬、方向分數與超額報酬的 Spearman IC |

尤其應檢查：

> 方向分數越高，命中率與平均報酬是否單調提高？

如果分數 8～10 分的表現沒有比 5～7 分好，就代表方向分數沒有校準好，單純提高進場門檻未必會改善結果。

## 最重要的判斷

這一天的結果尚不能證明「偏多規則比較差」。

比較合理的解讀是：

> 模型整體方向能力偏弱，當日命中率 47.28%；偏空表面上優於偏多，但差距主要與當天下跌股票較多一致。真正較值得追查的是七日相對強勢的負關聯，以及分數是否存在過度延續、過熱或因子重複計分。

在調整正式規則前，應先把評估從「原始命中率」升級成「市場校正後的命中率＋實際策略報酬＋數字誤差」。
