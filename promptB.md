# `promptB` repository command

When the repository owner sends `promptB`, do not treat the word itself as the closeout acceptance contract.

Execute the canonical repository closeout runner protocol at:

`docs/agent-prompts/prompt-b-runner.md`

Mandatory first steps are still to fetch current remote `main` and read repository-root `AGENTS.md`. The correct phase-specific Prompt B must be recovered for the most recent round whose Prompt A is complete but Prompt B PASS is not yet durable, using preregistered durable repository history rather than document position or conversation history.
